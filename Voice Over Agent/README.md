# Voice Over Agent (বাংলা এআই ভয়েস-ওভার এজেন্ট)

এই এজেন্টটি **Writer Agent**-এর তৈরি করা স্ক্রিপ্ট (`.docx` বা `.txt`) ফাইল থেকে **১০০% প্রাকৃতিক, মানবীয় ও রিয়েল মানুষের মতো** বাংলা ভয়েস-ওভার অডিও তৈরি করে। এতে কোনো রোবোটিক বা যান্ত্রিক টান নেই।

---

### ৩টি জনপ্রিয় প্রিমিয়াম কণ্ঠ

| কণ্ঠের নাম | ধরন | বৈশিষ্ট্য |
|---|---|---|
| **Kore** | নারী (Female) | মিষ্টি, সাবলীল ও বাস্তব মানুষের মতো স্বাভাবিক বাচনভঙ্গি (টেলিগ্রাম ডেমোর মতো) |
| **Aoede** | নারী (Female) | স্পষ্ট, দৃঢ় ও পেশাদার টিভি সংবাদ উপস্থাপিকার মতো কণ্ঠ |
| **Charon** | পুরুষ (Male) | গম্ভীর, ব্যক্তিত্বসম্পন্ন ও আকর্ষণীয় পুরুষ সংবাদ উপস্থাপকের কণ্ঠ |

---

### প্রধান সুবিধাসমূহ
1. **১০০% রিয়েল হিউম্যান কোয়ালিটি:** সাধারণ টিটিএসের মতো যান্ত্রিক সুর নয়, এতে মানুষের স্বাভাবিক ওঠানামা, নিঃশ্বাস ও আবেগময় উচ্চারণ থাকে।
2. **মাল্টি-API Failover Pool (৬টি API Key সাপোর্ট):** `.env`-এ `GEMINI_API_KEY_1` থেকে `GEMINI_API_KEY_6` (বা তার বেশি) দিতে পারবেন। কোনো একটি কী-তে রেট-লিমিট বা কোটা শেষ হলে স্বয়ংক্রিয়ভাবে পরেরটিতে সুইচ করবে, ফলে স্ক্রিপ্ট তৈরি কখনই মাঝপথে বন্ধ হবে না।
3. **এমার্জেন্সি ব্যাকআপ (Edge-TTS):** যদি সাময়িকভাবে সব জেমিনি কী-এর দৈনিক লিমিট শেষ হয়ে যায়, তবে ব্যাকআপ হিসেবে Edge-TTS দিয়ে সম্পূর্ণ স্ক্রিপ্টের কাজ নিখুঁতভাবে শেষ করবে।
4. **নিখুঁত বাংলা উচ্চারণ:** সংখ্যা (যেমন: ২ কোটি ৭০ লাখ ➔ দুই কোটি সত্তর লাখ), তারিখ, ইংরেজি শব্দ (OpenAI ➔ ওপেন এআই) বাংলায় স্বয়ংক্রিয়ভাবে স্বাভাবিক উচ্চারণে রূপান্তর হয়।
5. **ফুল ও সেগমেন্ট অডিও:**
   - **সম্পূর্ণ অডিও (`full_voiceover_<voice>.mp3`):** সংবাদের মাঝের স্বাভাবিক বিরতি সহ একটানা শোনার মতো ফুল ট্র্যাক।
   - **সেগমেন্ট অডিও (`segments_<voice>/`):** প্রতিটি খবরের আলাদা আলাদা অডিও ফাইল (CapCut বা Premiere Pro-তে টাইমলাইনে সাজানোর জন্য)।

### ব্যবহারের নিয়মাবলী

#### এক ক্লিকে চালানো (Windows):
সরাসরি `run.bat` ফাইলে ডাবল ক্লিক করুন। নিচের মেনু আসবে:
```text
  [1] Kore   - মিষ্টি, সাবলীল ও বাস্তব নারী কণ্ঠ (ডেমো অডিওর মতো)
  [2] Aoede  - স্পষ্ট ও পেশাদার টিভি সংবাদ উপস্থাপিকার নারী কণ্ঠ
  [3] Charon - গম্ভীর ও ব্যক্তিত্বসম্পন্ন পুরুষ সংবাদ উপস্থাপকের কণ্ঠ
  [4] ALL    - সব ৩টি কণ্ঠেই আলাদা আলাদা ফুল অডিও তৈরি
  [5] বের হন
```
আপনার পছন্দের নম্বর চেপে Enter দিন।

#### কমান্ড লাইন দিয়ে চালানো:
```bash
# ডিফল্ট (Kore নারী কণ্ঠ)
python main.py

# Aoede (টিভি উপস্থাপিকা কণ্ঠ)
python main.py --voice aoede

# Charon (পুরুষ সংবাদ উপস্থাপক কণ্ঠ)
python main.py --voice charon

# সব ৩টি কণ্ঠেই একসাথে তৈরি করতে
python main.py --voice all
```
