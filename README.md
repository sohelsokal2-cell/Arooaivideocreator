# 🚀 AI Reels Creator — বাঙালি ফ্যাক্টস (@bangaliifacts)

সম্পূর্ণ স্বয়ংক্রিয় এআই রিলস ক্রিয়েশন ও সোশ্যাল মিডিয়া পাবলিশিং মাল্টি-এজেন্ট পাইপলাইন।

## 🤖 আর্কিটেকচার ও এজেন্টসমূহ

1. **News Collector Agent**: একাধিক বিশ্বস্ত সংবাদ সোর্স থেকে সত্য খবর সংগ্রহ ও বিশ্লেষণ।
2. **Writer Agent**: ৪৫-৬০ সেকেন্ডের খাঁটি বাংলা রিল স্ক্রিপ্ট তৈরি।
3. **Voice Over Agent**: স্টুডিও কোয়ালিটি বাংলা ভয়েস-ওভার জেনারেশন (১০টি জেমিনি কি ফেইলওভার পুল সহ)।
4. **Image Editor Agent**: ব্র্যান্ডেড রিল স্লাইড ও নিউজ কার্ড ডিজাইন।
5. **Video Creator Agent**: ১০৮০x১৯২০ ভার্টিক্যাল এইচডি ভিডিও কম্পোজিশন ও সাবটাইটেল রেন্ডারিং।
6. **Thumbnail Creator Agent**: ৯:১৬ এবং ১৬:৯ পরিষ্কার থাম্বনেইল কভার মেকার।
7. **Facebook Page Manage Agent**: মেটা গ্রাফ এপিআই ইন্টিগ্রেশন ও সরাসরি ফেসবুক রিলস পাবলিশিং।
8. **YouTube Page Manage Agent**: গুগল ক্লাউড OAuth 2.0 ইন্টিগ্রেশন ও ইউটিউব শর্টস অটো-আপলোডার।
9. **Voice Assistant Agent**: সেন্ট্রাল কন্ট্রোল ড্যাশবোর্ড, রিয়েল-টাইম কনসোল, এপিআই হাব ও ভয়েস সহকারী।

## 🛠️ সেটআপ ও রান করার নিয়ম

### ১. লাইব্রেরি ইনস্টল করুন
```bash
pip install -r requirements.txt
```

### ২. সেন্ট্রাল ড্যাশবোর্ড চালু করুন
```bash
run.bat
```
অথবা:
```bash
cd "Voice Assistant Agent"
python launch_ui.py
```
ব্রাউজারে খুলুন: `http://localhost:5000`
